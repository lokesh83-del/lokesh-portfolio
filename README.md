# Lokesh Kumar — Personal Portfolio

A responsive editorial-style portfolio inspired by the supplied Mondragon / creative portfolio references.

## Run locally
1. Unzip the folder.
2. Open `index.html` in a browser, or run a local server from this folder:
   - `python3 -m http.server 8000`
   - visit `http://localhost:8000`

## Included
- Responsive layout for desktop and mobile
- Your supplied portrait in `assets/lokesh-portrait.jpg`
- Smooth anchor scrolling, scroll reveals, progress indicator, subtle parallax
- Custom cursor and magnetic CTA on pointer devices
- Reduced-motion accessibility support
